# ADR 0002: 學習建議一鍵套用關卡設定

- 狀態：Accepted
- 日期：2026-02-23
- 決策者：vibe-lab/math-practice 維護者

## 背景

ADR 0001 已在結果頁提供規則式「學習建議」，但使用者仍需手動切回設定區並逐欄輸入，摩擦較高。  
需求是讓每則建議可直接套用，縮短從「看到建議」到「開始針對性練習」的流程。

## 決策

在每則學習建議卡片新增 `套用此建議關卡` 按鈕，點擊後執行以下流程：

1. 回到設定畫面（隱藏結果頁）。
2. 自動回填建議對應設定（題型、題目數、時間模式、秒數、加減上限、乘除範圍）。
3. 保留血條設定與音效設定不變，避免覆蓋使用者偏好。

## 規則與範圍

### 回填欄位

- 題目種類：切為單一建議題型（加/減/乘/除）
- 題目數量：
  - 高錯誤率：`12` 題
  - 中錯誤率平衡訓練：`18` 題
  - 偏慢提速：`12` 題
- 單題答題時間：
  - 正確率強化：`無時間限制`
  - 平衡訓練：`15` 秒
  - 提速訓練：`10` 秒
- 加減上限：
  - 高錯誤率時降一級（最低保留個位數）
- 乘除出題範圍：
  - 高錯誤率優先 `9x9`
  - 其他情境沿用當前範圍（若無則預設 `9x9`）

### 不回填欄位

- 血條設定
- 音效設定

## 為何不選擇其他方案

### 方案 A：僅顯示建議文字，不提供回填

- 優點：實作簡單。
- 缺點：使用者仍需手動操作，容易放棄。
- 決議：不採用。

### 方案 B：按下即直接開始練習（跳過設定畫面）

- 優點：操作步數最少。
- 缺點：可見性與可控性較差，使用者不易確認回填內容。
- 決議：目前不採用，先回到設定區讓使用者可檢查後再開始。

## 影響與後續

### 正面影響

- 降低操作成本，讓學習建議更可執行。
- 保留設定畫面確認步驟，兼顧效率與可控性。

### 風險

- 預設回填數值屬 MVP 經驗值，仍需依實際使用反饋微調。

### 延伸方向

- 增加「套用並開始練習」快捷按鈕。
- 在按鈕下方顯示「已套用」狀態提示。
- 記錄建議套用率，作為規則優化依據。
