# 社群預覽圖提案：成果型（result style）

## 1) 目標與使用情境
- 目標：凸顯「不只練習，還能看到成果與弱點」的價值。
- 使用情境：分享產品功能完整度、教師或家長回顧成果貼文。

## 2) 核心訊息
- 主標：`作答成果看得見，弱點補強更精準`
- 副標：`答對答錯統計、學習建議、PDF 留存一次完成`

## 3) 視覺語言
- 風格：資訊清楚、專業、可信。
- 語氣：結果導向、可追蹤。
- 圖像重點：結果頁截圖為主角，搭配重點標示。

## 4) 版面配置（1200x630）
- 畫布：`1200 x 630`
- 安全區：四邊各 `60px`
- 左區（成果文案）：`x=80~620, y=90~540`
- 右區（結果頁截圖）：`x=650~1120, y=80~550`
- 背景：淺灰藍底，凸顯資料卡片。

## 5) 元件清單
- 主標（1~2 行）
- 副標（1 行）
- 三個成果標籤
  - `答對答錯統計`
  - `學習建議`
  - `下載 PDF`
- 結果頁截圖（建議使用 `images/05_作答結果.png`）
- 角標：`數學計算練習`

## 6) 文案定稿
- 主標：`作答成果看得見，弱點補強更精準`
- 副標：`答對答錯統計、學習建議、PDF 留存一次完成`
- 輔助行（可選）：`每一輪練習都能作為下一輪的依據`

## 7) 色彩與字體建議
- 背景：`#F1F5F9` → `#E2E8F0`
- 主標文字：`#0F172A`
- 副標文字：`#334155`
- 標籤底色：`#0EA5E9`
- 標籤文字：`#FFFFFF`
- 建議字體：Noto Sans TC（主標 700、內文 500）

## 8) 跨平台裁切注意事項
- 結果截圖的關鍵欄位（統計、學習建議）放在截圖中央。
- 不要塞太多小字，平台縮圖時會失去可讀性。
- 副標長度控制在 22~28 字以內。

## 9) 製作流程建議
1. 設定灰藍背景與安全區。
2. 放左側主標、副標、成果標籤。
3. 放右側結果頁截圖，適度裁切並加邊框陰影。
4. 檢查整體閱讀順序：主標 -> 標籤 -> 截圖。
5. 匯出 PNG 並做三平台預覽測試。

## 10) 驗收檢查表
- [ ] 一眼可看出「有結果分析」而非只有題目畫面。
- [ ] 三個成果標籤都對應真實功能。
- [ ] 截圖清晰且不被壓縮糊化。
- [ ] 主副標在手機縮圖下仍可讀。
- [ ] Facebook/Threads/Twitter 預覽皆維持同一視覺重點。
