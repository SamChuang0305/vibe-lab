# 社群預覽圖提案：實戰型（combat style）

## 1) 目標與使用情境
- 目標：讓使用者在 1 秒內理解這是「可立即開始」的國小四則運算練習工具。
- 使用情境：Facebook、Threads、Twitter 分享首頁連結時的預覽大圖。

## 2) 核心訊息
- 主標：`國小四則運算線上練習`
- 副標：`限時挑戰、血條模式、學習建議一次到位`

## 3) 視覺語言
- 風格：乾淨、明亮、行動導向。
- 語氣：直接、明確、鼓勵開始練習。
- 圖像重點：右側展示手機作答畫面，左側給關鍵賣點。

## 4) 版面配置（1200x630）
- 畫布：`1200 x 630`
- 安全區：四邊各 `60px`（重要文字與按鈕均放在安全區內）
- 左區（文案）：`x=80~680, y=90~540`
- 右區（裝置圖）：`x=720~1120, y=70~560`
- 背景：由深藍到藍綠的漸層，增加對比與辨識度。

## 5) 元件清單
- 主標（1 行）
- 副標（1 行）
- 三個功能標籤（pill）
  - `四則運算`
  - `限時挑戰`
  - `血條模式`
- 手機框 + 作答截圖（建議使用 `images/04_作答畫面（手機）.png`）
- 品牌角標：`數學計算練習`

## 6) 文案定稿
- 主標：`國小四則運算線上練習`
- 副標：`限時挑戰、血條模式、學習建議一次到位`
- 輔助行（可選）：`免費使用，手機、平板、電腦都能練`

## 7) 色彩與字體建議
- 主背景：`#0B3A8F` → `#0E7490`
- 主標文字：`#F8FAFC`
- 副標文字：`#E2E8F0`
- 標籤底色：`#1D4ED8`
- 標籤文字：`#FFFFFF`
- 建議字體：Noto Sans TC（粗體 700、一般 500）

## 8) 跨平台裁切注意事項
- Facebook/Threads/Twitter 皆以中央區域優先顯示，主標與手機截圖不可貼邊。
- 避免將重點放在左右 40px 內。
- 文字不超過 2 行，減少小螢幕被壓縮後的可讀性問題。

## 9) 製作流程建議
1. 建立 1200x630 畫布與 60px 安全區參考線。
2. 先放背景漸層，再放左側標題區。
3. 匯入手機截圖，套圓角與陰影。
4. 放入三個功能標籤，最後加品牌角標。
5. 匯出 PNG，檔名 `social_preview_1200x630.png`。

## 10) 驗收檢查表
- [ ] 主標在手機預覽仍清晰可讀。
- [ ] 右側裝置圖不超出安全區。
- [ ] 三個功能標籤內容與產品實際功能一致。
- [ ] 深淺對比足夠（文字不糊、不灰）。
- [ ] 貼到 Facebook/Threads/Twitter 時，關鍵資訊不被裁切。
