# 社群預覽圖提案：親子陪學型（parent child style）

## 1) 目標與使用情境
- 目標：傳達「家長可陪孩子在家穩定練習」的安心感與可持續性。
- 使用情境：親子社團、家長社群、教育社群分享。

## 2) 核心訊息
- 主標：`每天 10 分鐘，陪孩子穩定進步`
- 副標：`可自訂難度與題型，在家也能有效練習`

## 3) 視覺語言
- 風格：溫暖、親切、低壓力。
- 語氣：陪伴式、鼓勵式。
- 圖像重點：柔和底色 + 手機畫面卡片 + 正向文案。

## 4) 版面配置（1200x630）
- 畫布：`1200 x 630`
- 安全區：四邊各 `60px`
- 左區（情境文案）：`x=90~700, y=100~520`
- 右區（裝置與點綴）：`x=730~1120, y=90~550`
- 背景：暖色系漸層與淡色圓形幾何點綴。

## 5) 元件清單
- 主標（1~2 行）
- 副標（1 行）
- 三個陪學賣點
  - `自訂難度`
  - `限時 / 無限時切換`
  - `結果回饋與學習建議`
- 手機截圖（設定頁或作答頁）
- 輕量裝飾圖形（圓點、線條）

## 6) 文案定稿
- 主標：`每天 10 分鐘，陪孩子穩定進步`
- 副標：`可自訂難度與題型，在家也能有效練習`
- 輔助行（可選）：`從個位數到百位數，循序建立計算信心`

## 7) 色彩與字體建議
- 主背景：`#FFF7ED` → `#FFEDD5`
- 主標文字：`#9A3412`
- 副標文字：`#7C2D12`
- 強調色：`#0EA5E9`（功能標籤或按鈕樣式）
- 建議字體：Noto Sans TC（主標 700、內文 500）

## 8) 跨平台裁切注意事項
- 溫暖背景要保留足夠留白，避免預覽縮圖時變得雜亂。
- 文字區與手機圖保持至少 36px 間距。
- 重要詞（每天 10 分鐘、穩定進步）放在中央偏左位置。

## 9) 製作流程建議
1. 先完成暖色漸層背景與裝飾形。
2. 放入主標、副標，調整行距讓小螢幕仍可讀。
3. 匯入手機畫面並加柔和陰影。
4. 加入三個賣點標籤，確保不超過兩行。
5. 匯出 PNG 並在社群平台預覽測試。

## 10) 驗收檢查表
- [ ] 整體觀感溫和，不像促銷廣告。
- [ ] 主標在縮圖狀態仍可辨識。
- [ ] 賣點語句簡潔，不超過三個重點。
- [ ] 手機畫面與文案不互相干擾。
- [ ] 各平台預覽時主標與裝置圖皆完整可見。
