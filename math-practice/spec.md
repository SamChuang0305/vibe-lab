## 使用技術

- HTML

## 前端樣式載入規格

- `index.html`、`user-guide.html` 僅可載入本地 `styles/tailwind.css`，不得使用 `https://cdn.tailwindcss.com` runtime script。
- Tailwind 來源檔為 `styles/input.css`，由 `tailwind.config.js` 掃描 `index.html` 後產生輸出。
- 樣式建置命令：
  - `npm run build:css`：一次性編譯
  - `npm run watch:css`：開發期間即時編譯

## 功能概述

- 隨機產生數學計算題目。
- 題型固定為 a、b 兩個數字做四則計算。
- 題目中的 a、b 兩個數字都不會小於 `0`。
- 若題目種類為乘法或除法，題目中的 a、b 兩個數字都不會出現 `1`。
- 若題目種類為減法或除法，題目中的 a、b 兩個數字不會相同。
- 加法、減法計算題目的數字範圍可設定為：
  - 個位數（`1~9`）
  - 十位數（`1~99`）
  - 百位數（`1~999`）
- 乘法、除法計算題目的出題範圍可設定為（至少必須選一種，可複選）：
  - `9x9` 乘法表（`2x2 ~ 9x9`）
  - `20x20` 乘法表（`11x2 ~ 20x20`）
  - 當題目種類未勾選乘法、除法時，可不設定乘除出題範圍。
- 題目種類至少必須選一種，可複選。
- 題目計算結果不會小於 0、只會有整數。
- 不會出現重複題目。
- 畫面一次只顯示一題。
- 可透過設定決定題目種類、題目數量、加、減法出題數字、乘除出題範圍、是否限時、血條設定、積分顯示、音效。
- 作答結果會依題目列表表現產生「學習建議」，提供針對題型的關卡設定與練習目標。
- `index.html` 與 `user-guide.html` 頂部顯示共用 Banner 圖：`./images/social_preview_1200x630.png`（1200x630）。
- `index.html` 列印結果頁（PDF）時，Banner 不顯示，避免影響匯出版面。

## 作答流程

- 顯示內容：題目、答案輸入框、`送出` 按鈕、`清空` 按鈕、`離開` 按鈕、目前題號、剩餘時間、血量、目前積分（可關閉顯示）。
- 從設定頁點擊 `開始練習` 進入作答頁時，畫面會自動回到頁面頂部。
- 作答區上方（`第 x/x 題` 與 `剩餘時間：xxx` 中間）顯示目前血量。
- 題目右側提供喇叭按鈕可切換音效開關（`🔊/🔇`），切換後會同步更新關卡設定的音效狀態。
- 點擊喇叭按鈕切換音效後，焦點會自動回到答案輸入框，方便直接繼續作答。
- 題目右側喇叭按鈕下方顯示 `目前積分 xxx`，靠右對齊，字體樣式與 `第 x/x 題` 相同。
- 點擊 `送出` 後進入下一題。
- 若啟用限時，時間到會自動判定該題超時；若血量未歸零則進入下一題，血量歸零則先顯示 `💥 GAME OVER！` modal。
- 輸入框支援按 `Enter` 送出。
- 輸入框支援按 `Esc` 清空。
- 輸入框送出前會自動移除前後空白。
- 作答區上方中間一律顯示血條狀態（`🛡 無敵` 或血量，例如：`❤️❤️❤️🖤🖤`）。
- 當血條設定為 `❤️` 數量模式時：
  - 答錯會扣 `1` 血。
  - 超時會扣 `1` 血。
  - 未輸入答案或答案格式錯誤只顯示提示，不扣血。
  - 血量扣到 `0` 會先跳出 modal 顯示 `💥 GAME OVER！`。
  - 點擊 modal 的 `[關閉]` 後，才會結束作答並顯示結果頁。
- 當音效設定為「開啟」時：
  - 送出且答對會播放答對音效。
  - 送出且答錯會播放答錯音效。
  - 超時會播放超時音效。
  - 血量扣到 `0` 並顯示 `💥 GAME OVER！` modal 時，會播放爆炸音效。
  - 若該題會使血量歸零，則只播放爆炸音效，不播放原本的答錯/超時音效。
- 積分規則：
  - 每答對一題可得 `100` 積分。
  - 每連續答對每滿 `5` 題，依連續區間加送積分：第 `5` 題加送 `250`、第 `10` 題加送 `500`、第 `15` 題加送 `750`，依此類推。
  - 答錯或超時不扣分，但連續答對數量歸 `0` 重新計算。
  - 範例：
    - 連續答對 `5` 題：基本 `500` + 加送 `250` = `750`
    - 連續答對 `10` 題：基本 `1000` + `250` + `500` = `1750`
    - 連續答對 `15` 題：基本 `1500` + `250` + `500` + `750` = `3000`
    - 連續答對 `20` 題：基本 `2000` + `250` + `500` + `750` + `1000` = `4500`
- 點擊 `清空` 會清除當前答案輸入。
- 點擊 `離開` 會跳出確認視窗：`確認要離開？將會直接顯示作答結果`
  - 按下確認後，立即結束作答並直接顯示作答結果。
  - 結果頁會額外顯示提示文字：`提早結束`。
  - 進入作答結果頁時，畫面會自動回到頁面頂部。

## 操作教學（下載 PDF）

1. 完成作答後，進入 `作答結果` 頁面。
2. 點擊 `下載 PDF` 按鈕。
   - 瀏覽器會開啟列印視窗；請選擇「另存為 PDF」。
3. 在列印視窗確認紙張、邊界與頁面範圍後，儲存 PDF。
4. 若出現錯誤提示，可重新點擊一次，或重新整理頁面後再試。

## 已知限制（PDF 匯出）

- PDF 匯出依賴瀏覽器原生列印功能，版面會受瀏覽器版本與列印設定影響。
- 建議在列印視窗選擇 A4 與適當邊界，以避免內容被截斷。
- 題目數量很多（例如 200 題）時，列印預覽與輸出時間會增加，屬正常現象。

## 使用者操作說明頁（`user-guide.html`）

- 對象：終端使用者（非開發者、無技術背景）。
- 內容定位：以實際操作流程為主，不描述實作細節。
- 至少涵蓋：
  - 快速開始流程
  - 關卡設定欄位說明
  - 作答流程與常用操作
  - 結果頁重點
  - 下載 PDF 操作
  - 常見問題
- 維護規則：後續若功能、按鈕名稱、頁面流程異動，必須同步更新 `user-guide.html`。

## 防呆與提示樣式

- 設定驗證失敗時顯示醒目的錯誤提示框（紅色樣式）。
- 驗證失敗的欄位會加上紅色高亮邊框與外框。
- 當題目數量超過目前設定可產生的不重複題目上限時，提示訊息會顯示「目前最多可出 xx 題」。
- 作答時若未輸入答案就送出，顯示警示提示框（黃色樣式）並高亮答案欄位。
- 使用者重新輸入時，錯誤提示與高亮會自動清除。

## 響應式與手機體驗

- 手機版將主要按鈕放大並改為全寬，包含：
  - 開始練習
  - 送出
  - 清空
  - 離開
  - 重新開始
  - 下載 PDF
- 桌面版維持自動寬度按鈕，以保留版面緊湊性。
