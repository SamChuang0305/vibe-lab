# 數學計算練習

## 使用技術

- HTML
- JavaScript
- Tailwind CSS

## 功能概述

- 隨機產生數學計算題目。
- 題型固定為兩個數字做四則計算（`a + b` 或 `a - b` 或 `a * b` 或 `a / b`）。
- 題目中的兩個數字都不會小於 `0`。
- 題目種類至少必須選一種，可複選。
- 題目計算結果不會小於 0、只會有整數。
- 畫面一次只顯示一題。
- 可透過設定決定題目種類、題目數量、數字長度、是否限時。

## 設定區

- 題目種類
  - 加法計算
  - 減法計算
  - 乘法計算
  - 除法計算
- 題目數量
  - 輸入範圍：`1 ~ 200`（整數）
  - 預設值：`10`
- 要計算的數字長度
  - 個位數（1~9）
  - 十位數（10~99）
  - 百位數（100~999）
- 單題答題時間限制
  - 無時間限制
  - 限定秒數
    - 輸入範圍：`1 ~ 600`（整數）
    - 預設值：`10`

## 作答流程

- 顯示內容：題目、答案輸入框、`送出` 按鈕、`清空` 按鈕、`離開` 按鈕、目前題號、剩餘時間。
- 點擊 `送出` 後進入下一題。
- 若啟用限時，時間到會自動判定該題超時並進入下一題。
- 輸入框支援按 `Enter` 送出。
- 點擊 `清空` 會清除當前答案輸入。
- 點擊 `離開` 會跳出確認視窗：`確認要離開？將會直接顯示作答結果`
  - 按下確認後，立即結束作答並直接顯示作答結果。
  - 結果頁會額外顯示提示文字：`提早結束`。

## 結果顯示

- 所有題目完成後顯示：
  - 答對題數
  - 答錯題數
  - 題目列表（黑字）
    - 題號
    - 題目種類
    - 題目
    - 使用者答案
      - 答錯時顯示紅字
      - 超時顯示「超時」
      - 未作答顯示「(未作答)」
    - 正確答案（黑字）
    - 作答結果
      - 答錯顯示紅字「❌錯誤」
      - 超時顯示紅字「❌超時」
      - 未作答顯示紅字「❌未作答」
      - 正確時顯示綠字「🟢正確」
- 提供 `重新開始` 按鈕回到設定畫面。

## 防呆與提示樣式

- 設定驗證失敗時顯示醒目的錯誤提示框（紅色樣式）。
- 驗證失敗的欄位會加上紅色高亮邊框與外框。
- 作答時若未輸入答案就送出，顯示警示提示框（黃色樣式）並高亮答案欄位。
- 使用者重新輸入時，錯誤提示與高亮會自動清除。

## 響應式與手機體驗

- 手機版將主要按鈕放大並改為全寬，包含：
  - 開始練習
  - 送出
  - 清空
  - 離開
  - 重新開始
- 桌面版維持自動寬度按鈕，以保留版面緊湊性。
