# 數學計算練習

## 使用技術

- HTML
- JavaScript
- Tailwind CSS

## 功能概述

- 隨機產生數學計算題目。
- 題型固定為 a、b 兩個數字做四則計算。
- 題目中的 a、b 兩個數字都不會小於 `0`。
- 若題目種類為乘法或除法，題目中的 a、b 兩個數字都不會出現 `1`。
- 若題目種類為減法或除法，題目中的 a、b 兩個數字不會相同。
- 加法、減法計算題目的數字範圍可設定為：
  - 個位數（`1~9`）
  - 十位數（`1~99`）
  - 百位數（`1~999`）
- 乘法、除法計算題目的出題範圍可設定為（至少必須選一種，可複選）：
  - `9x9` 乘法表（`2x2 ~ 9x9`）
  - `20x20` 乘法表（`11x2 ~ 20x20`）
  - 當題目種類未勾選乘法、除法時，可不設定乘除出題範圍。
- 題目種類至少必須選一種，可複選。
- 題目計算結果不會小於 0、只會有整數。
- 不會出現重複題目。
- 畫面一次只顯示一題。
- 可透過設定決定題目種類、題目數量、加減數字上限、乘除出題範圍、是否限時、血條模式、音效。

## 關卡設定區

- 題目種類
  - 加法 ➕
  - 減法 ➖
  - 乘法 ✖️
  - 除法 ➗
- 題目數量
  - 輸入範圍：`1 ~ 200`（整數）
  - 預設值：`10`
- 加減數字上限
  - 個位數（1~9）
  - 十位數（1~99）
  - 百位數（1~999）
- 乘除出題範圍
  - 當題目種類有勾選乘法或除法時，至少必須選一種，可複選
  - 當題目種類未勾選乘法、除法時，可不設定
  - 9x9（2x2 ~ 9x9）
  - 20x20（11x2 ~ 20x20）
- 單題答題時間限制
  - 無時間限制
  - 限定秒數
    - 輸入範圍：`1 ~ 60`（整數）
    - 預設值：`10`
- 血條模式
  - 關閉（預設）
  - `❤️`
  - `❤️❤️`
  - `❤️❤️❤️`
  - `❤️❤️❤️❤️`
  - `❤️❤️❤️❤️❤️`
  - 答錯或超時會扣 `1` 血
  - 血量扣到 `0` 會跳出 modal 顯示 `💥 GAME OVER！`
  - modal 只可透過 `[關閉]` 按鈕關閉；關閉後才會結束作答並顯示結果頁
- 音效
  - 開啟（預設）
  - 關閉
- 說明

  - 若題目種類為減法或除法，題目中的 a、b 兩個數字不會相同。

    - 題目種類**只勾選**：`乘法 ✖️`

    - 題目數量設定：`64`。

## 作答流程

- 顯示內容：題目、答案輸入框、`送出` 按鈕、`清空` 按鈕、`離開` 按鈕、目前題號、剩餘時間、血量（啟用血條模式時）。
- 作答區上方（`第 x/x 題` 與 `剩餘時間：xxx` 中間）提供喇叭按鈕可切換音效開關（`🔊/🔇`），切換後會同步更新關卡設定的音效狀態。
- 點擊 `送出` 後進入下一題。
- 若啟用限時，時間到會自動判定該題超時；若血量未歸零則進入下一題，血量歸零則先顯示 `💥 GAME OVER！` modal。
- 輸入框支援按 `Enter` 送出。
- 輸入框支援按 `Esc` 清空。
- 輸入框送出前會自動移除前後空白。
- 當血條模式啟用時，題目下一行顯示血量（例如：`❤️❤️❤️🖤🖤`）。
- 當血條模式啟用時：
  - 答錯會扣 `1` 血。
  - 超時會扣 `1` 血。
  - 未輸入答案或答案格式錯誤只顯示提示，不扣血。
  - 血量扣到 `0` 會先跳出 modal 顯示 `💥 GAME OVER！`。
  - 點擊 modal 的 `[關閉]` 後，才會結束作答並顯示結果頁。
- 當音效設定為「開啟」時：
  - 送出且答對會播放答對音效。
  - 送出且答錯會播放答錯音效。
  - 超時會播放超時音效。
  - 血量扣到 `0` 並顯示 `💥 GAME OVER！` modal 時，會播放爆炸音效。
  - 若該題會使血量歸零，則只播放爆炸音效，不播放原本的答錯/超時音效。
- 點擊 `清空` 會清除當前答案輸入。
- 點擊 `離開` 會跳出確認視窗：`確認要離開？將會直接顯示作答結果`
  - 按下確認後，立即結束作答並直接顯示作答結果。
  - 結果頁會額外顯示提示文字：`提早結束`。

## 防呆與提示樣式

- 設定驗證失敗時顯示醒目的錯誤提示框（紅色樣式）。
- 驗證失敗的欄位會加上紅色高亮邊框與外框。
- 當題目數量超過目前設定可產生的不重複題目上限時，提示訊息會顯示「目前最多可出 xx 題」。
- 作答時若未輸入答案就送出，顯示警示提示框（黃色樣式）並高亮答案欄位。
- 使用者重新輸入時，錯誤提示與高亮會自動清除。

## 響應式與手機體驗

- 手機版將主要按鈕放大並改為全寬，包含：
  - 開始練習
  - 送出
  - 清空
  - 離開
  - 重新開始
- 桌面版維持自動寬度按鈕，以保留版面緊湊性。
